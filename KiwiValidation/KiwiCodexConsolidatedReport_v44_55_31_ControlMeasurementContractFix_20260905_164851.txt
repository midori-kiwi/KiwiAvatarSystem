1. Executive Summary

CONFIRMED RUNTIME FACT — v44.55.30 CONTROL did not fail through the launcher timeout. The Player itself exited with code 30. The failed Runtime ZIP is byte-preserved and its SHA256 equals the user-specified value.

CONFIRMED PRIMARY CAUSE — C2_V30_OBSERVER_LOGIC_DEFECT. v27 calculated parity and then intentionally released its observer-owned payload arrays. Later, v27 FinishPair called v30 RecordFinalPair. v30 RecordCore tried to bit-copy those already-null arrays. All 42 callbacks raised "Payload length". v30 had already inserted each record index into finalRecords before the exception, so finalPairs became 42 while eligiblePairs remained 0 and producer_pairs.jsonl remained empty.

CONFIRMED SECONDARY CAUSE — C4_LIFECYCLE_COMPLETION_DEFECT. v20 and v27 bootstrap hosts use HideFlags.DontSave. v30 Update tried to find them with FindFirstObjectByType<T>(). Unity 6000 documentation states that FindFirstObjectByType does not return objects with HideFlags.DontSave. v30 therefore never observed v27._reportWritten=true and did not enter its dependency-complete branch. At elapsed > 270 seconds it selected Finish("TIMEOUT") and Application.Quit(30).

SECONDARY OBSERVATION — C1_RUNTIME_INPUT_COVERAGE. The target run produced 42 eligible v27 pairs, below the fixed minimum 60. This is not the primary exit-30 explanation because the observer had already faulted 42/42 pairs and could not bind v27 completion. A separate immediately preceding CONTROL from the same v30 build identity produced 107 v20/v27 pairs in the same 120-second collection window, proving that the 60-pair gate is not intrinsically impossible. The target run's lower coverage remains runtime-variable and is not repaired or relaxed here.

DECISION — CHANGE_MEASUREMENT_SYSTEM. v44.55.31 is diagnostic-only and named by contract KIWI_V44_55_31_CONTROL_MEASUREMENT_CONTRACT_FIX. Production inference, publication, camera, tracking, ROI, thresholds, FacePart, Provider, Spout, Native DLL, Inference package, backend, cadence, queue, and synchronization semantics were not changed.
