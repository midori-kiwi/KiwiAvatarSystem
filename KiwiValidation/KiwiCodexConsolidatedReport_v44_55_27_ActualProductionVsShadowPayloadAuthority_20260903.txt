Public Design Principles
========================
1. Installed Inference Engine 2.4.1 Worker source states that PeekOutput returns a
   reference valid only until the next Schedule, ScheduleIterable, or Dispose on
   that Worker. Therefore post-record reuse of a Worker-owned output cannot be
   assumed to preserve the completed transaction.
2. Installed Tensor source implements ReadbackAndClone by creating a new tensor,
   downloading logical count values, creating CPU tensor data, and copying those
   values. The Production call already exists; v27 does not add another call.
3. Claim-scoped authority requires payload ownership and transaction identity to
   be closed before comparing numeric results. A validator string, approximate
   numeric similarity, latest artifact, or canonical publication proxy alone does
   not establish actual decode payload authority.
4. Correctness observation must not perturb scheduling. v27 therefore consumes
   existing CPU-owned payloads and existing v24 snapshots without adding a Worker,
   Schedule, GPU copy, queue, fence, or blocking wait.

   long-session allocation behavior.

confirmed actual Production authority. Do not add a GPU wait or Production clone
fix merely because Actual differs from both shadows.
