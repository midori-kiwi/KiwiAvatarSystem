KiwiAvatarSystem Core Rules

Status: DURABLE_BASELINE

1. Authority / 時系列
Claim-Scoped Authority。Implementation=current local Production source+SHA、Runtime=same-build/same-Production、Package=実使用Package Source、Performance=clean Production benchmark、Visual=same-build Human review。通常Chatがlive localを直接確認できない時はNORMAL_CHAT_LIVE_LOCAL_PRODUCTION_NOT_DIRECTLY_VERIFIED。Codex REPORTのSHA/HEADはreport-time snapshotで現在へ自動昇格しない。GitHub remote/mainがlocalより古ければProduction Authorityにしない。EXE/DLL SHA単独をsource/build reproducibility Authorityにしない。SHA推測禁止。Unknown!=PASS、Unknown!=Failure。Observer/Validator/Benchmark/REPORT自身も監査対象。
時系列もAuthorityの一部。新Evidenceが旧Current/Next/SHAをSupersedeしたら再昇格しない。ChatReport=履歴、CurrentRoadmap=現在状態、CoreRules=恒久契約。

2. 開発原則
正常なProductionを理由なく再設計しない。変更前にcurrent local source/Runtime、実Package Source、official Source/docs、類似OSS/公開商用方式をclaim単位で比較し、correctness/latency/authority/transaction/lifecycle/resource/rollbackを評価。証明済みfirst boundaryだけ最小修正し、複数unknownを同時修正しない。前提/identity/proxy/observer/validator/benchmark defectなら測定設計まで戻る。Big-Bang rewrite、external tracker Primary置換、Neural replacement Primary化=REJECT。外部流用=SELECTIVE/EVIDENCE-GATED、採用時は旧owner retire。

3. Tracking / Transaction
Face Landmarker=Primary/Source of Truth。正常sampleを最小latencyでAvatarへ届け、異常sample/transition/presentation破綻だけ局所抑制。latest-frame、persistent ROI、bounded/nonblocking lanes、freshness/liveness/source age分離。FIFO、stale queue、permanent frame buffer、stale prediction、strong smoothing/Kalman、根拠なきthreshold緩和禁止。Camera/Inference/Presentation問題をtracking mathで隠さない。
Root/Head/Eye/Mouth分離、Head=single rigid authority。Yaw/Pitch/RollやBlink/Mouth/EyeをRoot translationへ混入しない。Provider normalization owner=1、Resume!=Provider Switch、Temporal Presentation owner=1/channel、Prediction owner=1/channel。duplicate/out-of-order/stale/mixed epoch publish禁止。Texture/Crop/Mask/FacePart=same-sample transaction。model-specific処理はTracking Core外。

4. Human-Head FacePart
Kiwi=変形しない剛体の人間頭部。Eye/Mouthのnon-rigid表情は残しsource rigid poseだけ除去→head-local/canonical appearance→existing fitted fixed surface→visible Kiwi Head rigid poseを1回適用。source appearance de-rigidization referenceとvisible Head authorityは別責務。billboard、2D facial 4x4 inverse UV、model deform補償をProduction解にしない。

5. Native / Inference
Windows/DX12優先。Native baselineは新Evidenceで置換されるまでPath B SystemMemoryNV12。fixed Unity-visible texture identity、session epoch!=frame sequence、latest/nonblocking。UpdateExternalTexture、IMFSample跨ぎ保持、FIFO/stale蓄積、D3D12 blocking Wait、rotating visible texture、D3D11On12 1080p禁止。Fence/queue flush/async disableはcausal boundary証明なしにProductionへ入れない。Native変更はsource→build definition/toolchain/flags→artifact→installed SHA→Runtimeで追う。速度だけでbackend採用しない。KiwiFaceMotion/KiwiInferenceFaceTrackerをcamera/display workaroundにしない。

6. Validation / Audit
Static/Package Sourceで閉じるclaimをRuntime化しない。Change-Local Gate、Contract Gate、Milestone Full Product Gateへ集約し、同claim多重observer、superseded diagnostic、毎version Full Runtime/Human Visualを削減。Final DoD=Source Identity→Transaction→Model Semantic→Canonical→Authority→Lifecycle→Resource→Replay→Security→Clean Performance→Compatibility→Final Human Visual→Distribution→Windows Acceptance。Human Visualをvalidator PASSで上書きしない。
KiwiAvatarSystemの技術的意味を持つ調査・設計・指示・実装・検証・評価・判断・成果物は原則FULL_AUDIT_1+FULL_AUDIT_2。各回同一scopeを100%独立監査。分割2-pass禁止。不一致=UNRESOLVED/STOP。副作用操作を監査回数だけを理由に二重実行しない。

7. Avatar / Product
Evidence-Protected Core + Avatar Adapter + Model Profile + Runtime Import + Transactional Hot Swap。VRM0/1、non-spherical、AutoFit、Spring/DangleはAdapter/Profile側。model-specific behaviorをCoreへ逆流させない。

8. 通常Chat / Codex / Tooling
通常Chat=外部調査、設計比較、Codex REPORT独立再監査、Runtime/Visual解釈、採用/Reject/Supersede、CurrentRoadmap更新。可能な限り通常Chat。Codex=live local source/SHA/provenance、exact method/dataflow、whole-file実装、PS5.1 Validator、compile/build/ABI/rollback、REPORT。
Codex指示はGOAL→Authority→current dataflow→target design→exact file/class/method→statement/equation→owner→identity/timestamp/generation→lifecycle/resource→implementation→禁止→Static Gate→必要時Runtime→validator自己監査→fixpoint→rollback→REPORT。commit/pushは明示時のみ。
コード変更前Preflight: ProjectVersion.txt、exact Unity.exe path、expected version一致、branch/HEAD/status、user-owned dirty保護、touched file before SHA、candidate SHA、after SHA。packages-lock変更時もcandidate SHA必須。mismatchはfail closed。reset/checkout/clean禁止。
Windows PowerShell 5.1固定。safe I/O、subprocess exit code、transactional replacement、rollback、write-target guard。PS7依存/ambiguous cardinality/unsafe I/O/obsolete path/versionを検出。Generic Listは::new()+.ToArray()。
Codex成果物はConsolidated REPORT優先、Runtime ZIPは必要時のみ。ZIP配布時はrootにREADME_FIRST.md、詳細TASK、必要資料、SHA manifest。不要なupload/downloadを増やさない。
