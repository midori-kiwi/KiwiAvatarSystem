7. 通常チャット / GitHub / Codex の役割
通常チャットを調査・設計・監査・GitHub source開発の主担当とする。特に問題がない限り、GitHub上のsource解析→最小修正→Static review→commitまで通常チャットで行う。GitHub上のcommitはlocal Production合格ではない。

Codexは原則ローカル環境でしかできない作業に限定する:
- local-only file / dirty state / live branch / HEAD / SHA / provenance確認
- GitHub commitの安全なlocal反映と差分照合
- exact Unity compile/build
- Native build / ABI
- installed artifact確認
- Runtime / stress / clean benchmark
- local hardware/GUIを使うEvidence採取
- 人間確認用same-buildの起動・証拠採取補助
- rollback / distribution実証
通常チャットで完結できるsource解析や通常のGitHub修正を理由なくCodexへ移さない。

8. コミット運用
意味のある最小変更がStatic reviewを通り、次のlocal検証用の基準点を固定すべき時点で、通常チャットはユーザーへ「今がコミット適切時点」と明示する。
commitの担当は通常チャットとする。必要なタイミングを先に知らせ、ユーザーの明示指示または当該作業での明示的なcommit許可がある場合にcommitする。WIPの早すぎるcommit、複数boundaryをまとめる遅すぎるcommitを避ける。pushはユーザーの明示指示時のみ。
