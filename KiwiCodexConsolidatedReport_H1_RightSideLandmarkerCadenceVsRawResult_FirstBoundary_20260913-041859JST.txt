Forward findings:
  a. Installed FaceLandmarker.BuildPacketsCallback allocates one
     FaceLandmarkerResult outside the callback closure. TryBuildFaceLandmarkerResult
     repopulates that result, and callbacks receive the same result/list graph on
     later callbacks. This reuse is serialized by the package callback lock.
  b. DetectAsync is explicitly latest/low-latency behavior and may drop accepted
     input images. A callback count lower than input/display cadence is therefore
     not itself a failure.
  c. FaceLandmarkerResultAnnotationController.DrawLater does not retain the raw
     callback graph. Under _currentTargetLock it calls FaceLandmarkerResult.CloneTo.
     CloneTo resizes destination lists, recursively CloneTo-copies each
     NormalizedLandmarks list, clears the destination landmark list, and AddRange
     value-copies readonly NormalizedLandmark structs. LateUpdate/SyncNow reads the
     copied destination while holding the same lock.
  d. The scene has renderDebugLandmarkAnnotations=0, and
     KiwiInferenceRecoveryBootstrap sets it false. Therefore the Package
     AnnotationController/DrawLater path is not the visible right-side sink in
     this Production configuration.
  e. The visible right-side sink is KiwiFrameComparisonOverlay, labelled
     MATCHED LANDMARK DEBUG. Its LateUpdate calls
     KiwiCanonicalTrackingFrame.TryGetSemanticLandmarksIfChanged, copies the
     canonical semantic array into its own landmark array, rebuilds a private
     overlay texture, and OnGUI draws only over the exact committed matched
     camera texture epoch.
  f. While Inference Engine is primary, MediaPipe StoreTrackingData updates only
     auxiliary data and does not publish the raw MediaPipe XY array. The actual
     right-side semantic source is then StoreSentisTrackingData/Inference Engine.
     Raw FaceLandmarkerResult and the right-side semantic sample are not the same
     transaction in those intervals.
  g. Storage is latest-snapshot based. No unbounded FIFO was found in the audited
     producer-to-visible path. Locks cover callback lifecycle, Runner snapshot
     swap/copy, Package annotation clone/read, and canonical snapshot copy.
