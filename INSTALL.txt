KiwiAvatarSystem v3.0.2 - Compile Hotfix
==========================================

This hotfix includes the previous v3.0.1 RigidCenter compile fix.

NEW FIX
-------
Assets\KiwiAvatarSystem\Editor\
  KiwiInferenceBackendHysteresisInstaller.cs

CAUSE
-----
The installer used:

  string.Replace(oldValue, newValue, 1)

C# `System.String.Replace` has no "replace only 1 occurrence" integer overload.
Unity therefore resolved the third argument against another overload and produced:

  CS1503: Argument 3: cannot convert from 'int' to 'System.StringComparison'

FIX
---
v3.0.2 no longer uses the invalid overload.

It now:
1. finds the exact field with IndexOf(..., StringComparison.Ordinal),
2. verifies that there is not a second matching field,
3. replaces only that exact occurrence using Substring.

No tracking thresholds or VTuber motion behavior were changed by this compile hotfix.

INSTALL
-------
1. Stop Play Mode.
2. Close Unity if possible.
3. Extract this ZIP.
4. Drag `Assets` onto:

   D:\KiwiAvatarSystem

5. Merge / replace all files.
6. Re-open Unity and wait for compilation.

Expected result:
- the CS1503 error in KiwiInferenceBackendHysteresisInstaller.cs disappears.
