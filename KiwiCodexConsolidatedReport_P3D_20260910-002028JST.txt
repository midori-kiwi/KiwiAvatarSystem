4. CURRENT SOURCE / INSTALLED PACKAGE LIFECYCLE PROOF
======================================================================

[Current Production Source]
KiwiFaceGeometryTransactionService.cs was audited as a whole.

GraphRun.TryEnterCallback:
- returns false without incrementing activeCallbacks when acceptingCallbacks=false.

GraphRun.RetireCallbacks:
- sets acceptingCallbacks=false;
- sets readyToDispose=(activeCallbacks==0).

TryDisposeRetiredRun:
- does nothing until IsReadyToDispose() is true;
- removes _retiredRun from service state;
- calls StopAndDisposeRun.

StopAndDisposeRun:
- calls Cancel();
- calls graph.Dispose();
- then unregisters the callback registry entry.

OnNativeOutput:
- reads the registry;
- calls TryEnterCallback;
- callbacks arriving after RetireCallbacks return OK without being included in
  activeCallbacks.

[Installed Managed Package]
CalculatorGraph derives from MpResourceHandle.
CalculatorGraph.DeleteMpPtr calls mp_CalculatorGraph__delete(ptr).
MpResourceHandle.DisposeUnmanaged calls DeleteMpPtr while it owns the resource.
Thus graph.Dispose() is the installed managed-to-native destruction call.

[Version-Matched Official Source]
Primary source:
https://raw.githubusercontent.com/google-ai-edge/mediapipe/v0.10.22/mediapipe/framework/calculator_graph.h

The ObserveOutputStream contract states that packet_callback may be called until
the CalculatorGraph object is destroyed, even after Cancel() or WaitUntilDone().
After object destruction the callback object is destroyed.

Supporting exact wrapper source:
https://raw.githubusercontent.com/homuler/MediaPipeUnityPlugin/v0.16.3/Packages/com.github.homuler.mediapipe/Runtime/Scripts/Framework/CalculatorGraph.cs

[Failure]
The current implementation uses a pre-destruction activeCallbacks==0 observation
as authorization to destroy and clear the retired run. It does not establish the
required ordered boundary:

  registry non-accepting
  -> Cancel/close
  -> native graph destruction
  -> no future callback boundary
  -> drain every callback that entered before/during destruction
  -> release registry/delegate/service callback state

No current source delta after the 22:48 superseding report repairs this boundary.

This is a Static/Package Source entry failure. A successful prior synthetic
shutdown instance cannot supersede the general callback lifetime contract.
